# Linear Equations & Systems

## Key ideas

To solve a single linear equation, do the same operation to both sides until the variable is isolated.

For **two equations in two unknowns**, use:

- **Substitution:** solve one equation for one variable and plug it into the other.
- **Elimination:** add or subtract multiples of the equations to cancel one variable.

> [!TIP]
> GMAT questions often ask for a *combination* like $x + y$, not for $x$ and $y$ separately. Look for a way to add or subtract the equations to get it directly.

> [!WARNING]
> Two equations don't always give a unique solution. If one equation is a multiple of the other (e.g. $x + 2y = 3$ and $2x + 4y = 6$), they are the same line and there are infinitely many solutions. This matters a great deal in Data Sufficiency.

## Worked example

**Problem.** If $3x + 2y = 17$ and $2x + 3y = 13$, what is $x + y$?

**Solution.** Add the equations: $5x + 5y = 30$, so $x + y = 6$. You never need $x$ or $y$ on their own.

## Practice

1. If $\dfrac{x}{3} + 4 = 2x - 1$, what is $x$?

<details>
<summary>Answer</summary>

Multiply by 3: $x + 12 = 6x - 3 \Rightarrow 15 = 5x \Rightarrow x = 3$.

</details>

2. Adult tickets cost \$12 and child tickets \$7. 50 tickets were sold for \$500. How many were adult tickets?

<details>
<summary>Answer</summary>

$a + c = 50$ and $12a + 7c = 500$. Substitute $c = 50 - a$: $12a + 350 - 7a = 500 \Rightarrow a = 30$.

</details>

3. If $4x - y = 11$ and $x + y = 9$, what is $y$?

<details>
<summary>Answer</summary>

Add the equations: $5x = 20$, so $x = 4$, and $y = 9 - x =$ **5**.

</details>

4. How many ordered pairs $(x, y)$ satisfy both $2x + 3y = 12$ and $4x + 6y = 24$?

<details>
<summary>Answer</summary>

The second equation is twice the first: they are the same line, so there are **infinitely many** solutions.

</details>

5. Five times a number, decreased by 8, equals three times the number plus 4. What is the number?

<details>
<summary>Answer</summary>

$5n - 8 = 3n + 4 \Rightarrow 2n = 12 \Rightarrow n =$ **6**.

</details>
