# Exponents & Roots

## Key ideas

> [!IMPORTANT]
> $$a^m a^n = a^{m+n} \qquad \frac{a^m}{a^n} = a^{m-n} \qquad (a^m)^n = a^{mn}$$
> $$a^0 = 1 \qquad a^{-n} = \frac{1}{a^n} \qquad a^{1/n} = \sqrt[n]{a}$$

### Common bases

To compare or solve with exponents, rewrite everything with the same base:

$$4^{x} = 8^{3} \;\Rightarrow\; 2^{2x} = 2^{9} \;\Rightarrow\; x = 4.5$$

### Simplifying roots

$\sqrt{ab} = \sqrt a\,\sqrt b$, so $\sqrt{72} = \sqrt{36 \cdot 2} = 6\sqrt2$.

> [!WARNING]
> $\sqrt{a + b} \ne \sqrt a + \sqrt b$, and $(a + b)^2 \ne a^2 + b^2$. Also, $\sqrt{x^2} = |x|$, not $x$.

> [!TIP]
> Factor out the smallest power: $2^{10} + 2^{12} = 2^{10}(1 + 4) = 5 \cdot 2^{10}$.

## Worked example

**Problem.** Simplify $\dfrac{3^{20} - 3^{18}}{3^{18}}$.

**Solution.** Factor the numerator: $3^{18}(3^2 - 1) = 8 \cdot 3^{18}$. Divide by $3^{18}$ to get **8**.

## Practice

1. If $9^{x+1} = 27^{x}$, what is $x$?

<details>
<summary>Answer</summary>

$3^{2x+2} = 3^{3x} \Rightarrow 2x + 2 = 3x \Rightarrow x = 2$.

</details>

2. Simplify $\sqrt{50} + \sqrt{18}$.

<details>
<summary>Answer</summary>

$5\sqrt2 + 3\sqrt2 = 8\sqrt2$.

</details>

3. If $5^{x+2} = 25^{x-1}$, what is $x$?

<details>
<summary>Answer</summary>

$25^{x-1} = 5^{2x-2}$, so $x + 2 = 2x - 2 \Rightarrow x =$ **4**.

</details>

4. Simplify $\dfrac{4^7}{8^3}$.

<details>
<summary>Answer</summary>

Rewrite with base 2: $\dfrac{2^{14}}{2^{9}} = 2^{5} =$ **32**.

</details>

5. Simplify $\sqrt{75} - \sqrt{12}$.

<details>
<summary>Answer</summary>

$5\sqrt3 - 2\sqrt3 = 3\sqrt3$.

</details>
