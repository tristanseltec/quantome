# Security Policy

Quantome is a static website. It has no server-side code, accounts or user data; reading progress is stored only in the reader's browser.

## Reporting a vulnerability

If you find a security issue, such as script injection through content or a compromised dependency, please **do not open a public issue**. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/tristanseltec/quantome/security/advisories/new).
We aim to respond within 7 days.

## Not security issues

Errors in mathematics or clinical content are not security issues. Please report them quickly and publicly with the
[Content error](https://github.com/tristanseltec/quantome/issues/new/choose) issue form. Clinical errors are given top priority.
